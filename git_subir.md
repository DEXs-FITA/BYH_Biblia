Ctrl + J = TERMINAL NUEVA

# 1. Crear y cambiar a nueva rama
git checkout -b optimizacion-pwa-v5

# 2. Verificar cambios pendientes
git status

# 3. Agregar todos los cambios
git add .

# 4. Crear commit
git commit -m "feat: optimizacion completa PWA v5.0.0"

# 5. Subir la nueva rama a GitHub
git push origin optimizacion-pwa-v5
